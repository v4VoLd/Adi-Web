## ⚡ Technical Highlights
- **Ultralight Architecture:** Pure Vanilla HTML5, modern CSS3, and JavaScript (~225 KB total payload). Zero heavy frameworks or bloated dependencies.
- **3D Fractured Metallic Halo Ring:** Dynamic 2D/3D projection engine with 70 depth-sorted faceted titanium shards, mouse parallax tilt, and smooth scroll dispersion.
- **CAN-Bus Telemetry & Flashing Simulator:** Interactive automotive terminal running UDS protocol ISO 14229 seed-key exchange simulations across Stage 1, Stage 2, and Big Turbo calibrations.
- **Interactive Dyno Stage Calculator:** Live HP and Torque gain calculator with visual progress bars across high-performance chassis (BMW M3 G80, Audi RS6 C8, Porsche 911 Turbo S, VW Golf 8 R, Mercedes-AMG C63, Toyota GR Supra).
- **Interactive Capability Launchpad:** 36-pad telemetry matrix with real-time protocol inspector (MED17, MG1CS024, Simos 18.1, DQ500 TCU).
- **Interactive Terminal HUD (`Ctrl + K`):** Developer-grade command line interface supporting interactive commands (`help`, `tune`, `cars`, `dyno`, `contact`, `clear`).
- **Brand Motorsport Palette:** Matched to ADI Performance's identity — Speed Yellow (`#FFD000`), Electric Blue (`#0156AD`), and Stealth Dark (`#080A0F`).

## 🚀 Running Locally
1. Start a local server:
   ```bash
   python -m http.server 8080
   ```
2. Open `http://localhost:8080/` in any modern desktop browser.
3. Or double-click `start_preview.bat`.
